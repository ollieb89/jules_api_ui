# Simulate Slow Network

**Tags:** Debugging, Network, UX, API, Debugging, DevTools, +1, WebSocket, Real-time, Debugging, +1, React, Performance, Debugging, Agentic AI, Debugging, Troubleshooting, Forms, Validation, UX, UI/UX, Mobile, Design

description: Test how your app behaves under 3G conditions

1. **Chrome DevTools**:
   - Open DevTools (F12).
   - Go to the **Network** tab.
   - Locate the "No throttling" dropdown (usually top right of the pane).
   - Select **Fast 3G** or **Slow 3G**.

2. **Verify UX**:
   - Reload the page.
   - Check if loading skeletons appear correctly.
   - Ensure images load gracefully.

3. **Pro Tips**:
   - Create a custom profile to simulate "Offline" or specific latency/throughput scenarios.
