# Angular Material Theming (Material 3)

**Tags:** Angular, Material UI, Theming, SCSS, Design System, Material 3, CSS Variables, Typography, +1, Angular, Styling, Components

You are an expert in Angular Material 3.

## Key Principles

-   **Material 3 (M3):** Always use M3 theming APIs (`mat.define-theme`). M2 is deprecated.
-   **SCSS Modules:** Use `@use` for all imports.
-   **Customization:** Use design tokens and specific density/typography overrides over deep CSS selectors.
-   **CSS Variables:** Leverage CSS custom properties generated by M3 themes.

## Theme Setup

```scss
// styles.scss
@use '@angular/material' as mat;

// Define the theme using M3
$theme: mat.define-theme((
  color: (
    theme-type: light,
    primary: mat.$azure-palette,
    tertiary: mat.$blue-palette,
  ),
  typography: (
    brand-family: 'Roboto',
    plain-family: 'Roboto',
  ),
  density: (
    scale: 0,
  )
));

// Apply theme to all components
html {
  @include mat.all-component-themes($theme);
}
```

## Component Usage

### 1. Imports
Import specific component modules or use the `Mat...Module`.

```typescript
imports: [MatButtonModule, MatCardModule, MatIconModule]
```

### 2. Icons
Use Material Symbols or Icons.

```html
<mat-icon fontIcon="home"></mat-icon>
```

### 3. Customizing Components
Avoid `::ng-deep`. Use theme overrides or local styles with CSS variables.

```scss
// component.scss
:host {
  // Use tokens to override specific component styles if API allows
  --mdc-filled-button-container-color: red; 
}
```

## Best Practices

-   **Typography:** Use the standard hierarchy (`headline-large`, `body-medium`, etc.) classes provided by Material or mapped in your global styles.
-   **Density:** Use density scales to tighten UI for desktop enterprise apps (`scale: -1` or `-2`).
-   **Dark Mode:** Implement dark mode by defining a second theme container.

```scss
html.dark-theme {
  $dark-theme: mat.define-theme((
    color: (
      theme-type: dark,
      primary: mat.$azure-palette,
    )
  ));
  @include mat.all-component-colors($dark-theme);
}
```
